One line, at most 200 characters: the commit message an AI agent leaves
after a long night fixing its own bugs.

`main.ts` (Node, no dependencies, no network) writes the commit message
to `/output/entry.txt` — one line plus exactly one trailing newline —
after validating the gate in characters, not bytes: 1–200 characters,
non-blank, single line, no control characters.

Run it:

```sh
node main.ts
```
